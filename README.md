# prod-ml-lab

Productionizing a machine learning model, one layer at a time. The model
predicts NYC taxi trip duration; the point is everything around it: honest
evaluation, serving, deployment, monitoring, failure, and safe retraining.
Inspired by Chip Huyen's *Designing Machine Learning Systems*.

Status: in progress. See [PLAN.md](PLAN.md) for the layers and failure modes.
